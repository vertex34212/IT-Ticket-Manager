## Figma-прототип

[Открыть редактируемый прототип IT Ticket Manager в Figma](https://www.figma.com/design/2uKVzo9PKUNHL4QuH4SUPk)

Прототип содержит шесть экранов для пользователя и IT-техника. Жизненный цикл заявки представлен статусами `Открыта → В работе → Решена → Закрыта`. Подтверждение решения пользователем является событием: после отказа заявка возвращается в работу, а закрытие выполняет техник после подтверждения.
