## Проверка конфиденциальности

Перед публикацией необходимо повторно проверить статус и содержимое Git:

```text
git status --short
git ls-files
git remote -v
```

В проекте используются только учебные материалы и публичная ссылка на Figma. Секреты, пароли, токены и приватные ключи в публикуемый набор не включаются.
