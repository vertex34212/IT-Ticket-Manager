Команды выполняются в локальной папке проекта:


На момент подготовки этого документа удалённый GitHub-репозиторий не был указан и не создан. После отдельного подтверждения публичной публикации здесь будут добавлены:

- фактическая команда добавления `origin`;
- фактически выполненная команда `git push`;
- реальная ссылка на GitHub;
- результат проверки опубликованных файлов.

## Проверка конфиденциальности

Перед публикацией необходимо повторно проверить статус и содержимое Git:

```text
git status --short
git ls-files
git remote -v
```

В проекте используются только учебные материалы и публичная ссылка на Figma. Секреты, пароли, токены и приватные ключи в публикуемый набор не включаются.
